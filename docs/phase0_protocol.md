# Phase-0 protocol

The only swept factor is white-noise standard deviation. The lesion, location,
sampling, matrix, and filtration are fixed. Metrics are defined before examining
results. Signal-present and signal-absent images use paired noise fields for the
topological contrast. H0 and H1 are analyzed separately.

The primary topology curve is paired H0 bottleneck distance. Secondary candidates
are H1 bottleneck distance and paired changes in total persistence, maximum
persistence, persistence entropy, thresholded feature count, and a landscape-norm
surrogate. Bootstrap intervals quantify Monte Carlo uncertainty.

Distance/persistence amplitudes are normalized by their known scaling under a
positive rescaling of filtration values. This prevents increasing noise amplitude
from being mistaken for increasing topological distinguishability.

The experiment cannot establish a thermodynamic phase transition. A segmented fit
is used only to identify candidate nonlinearity and is compared against a smooth
baseline using AIC. Finite-size scaling and changed-condition replication are held
for a subsequent experiment only if warranted by these results.
